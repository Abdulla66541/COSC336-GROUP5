# 5. Requirements Gathering

## 5.1 Requirements Gathering Methodology

The requirements for the Circular Campus system were gathered mainly by reviewing the project description and the course project slides. These documents were used to understand the main objectives of the system, the required features, the types of users, and the information that the system needs to store.

The project description was also used to identify the required classic system functions and the AI-based functions that should be included in the final system.
